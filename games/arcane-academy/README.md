# Arcane Academy — 3D School Adventure

A mobile-friendly stylized 3D school exploration prototype built with Three.js.

## Play
Open `index.html` through GitHub Pages or a local web server. An internet connection is needed to load Three.js from jsDelivr.

## Controls
- Mobile: left virtual joystick to move, JUMP button to jump
- Desktop: WASD or arrow keys to move, Space to jump
- Shift: run

## Current prototype
- Stylized fantasy academy with towers, courtyard, garden and lanterns
- Third-person follow camera
- Simple student character
- Keyboard and touch controls
